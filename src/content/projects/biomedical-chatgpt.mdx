## Overview

This early campus research project explored how speech recognition and a general-purpose language model API could support biomedical information workflows, including medical text handling and draft preparation.

## Prototype Workflow

The prototype linked automatic speech recognition with ChatGPT API responses, creating a natural-language interface for biomedical information tasks.

## My Contributions

I helped deploy and maintain the assistant prototype and reviewed literature and datasets to identify potential biomedical NLP use cases.

## Learning

The project introduced me to connecting existing AI capabilities with a concrete application workflow, an interest that later developed through more structured domain-data and RAG projects.

## 项目概述

这一早期校园科研项目探索将语音识别与通用大语言模型 API 结合，用于生物医学信息辅助处理，关注医疗文本处理及草拟等场景。

## 原型流程

原型将自动语音识别与 ChatGPT API 生成回复连接起来，为生物医学信息任务提供自然语言交互方式。

## 个人贡献

我参与助手原型的部署与维护，并通过文献和数据集调研梳理生物医学 NLP 的潜在应用场景。

## 收获

该项目让我开始接触将现有 AI 能力连接到具体应用流程的实践，也为后续更系统的领域数据处理与 RAG 研究奠定了兴趣基础。
